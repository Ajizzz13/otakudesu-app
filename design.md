# Design — Otakudesu Clean Stream

Locked design system for the anime streaming app.

## Genre
modern-minimal

## Macrostructure family
- App pages: Workbench (custom) — OSD header / remote search / grid-driven content / mono data labels.

## Theme
- `--color-ink`: #0a0a0c (deep night)
- `--color-panel`: #121216
- `--color-panel-2`: #1a1a22
- `--color-line`: #22222a
- `--color-accent`: #00dcff (electric cyan)
- `--color-accent-ink`: #0a0a0c
- `--color-data`: #00dcff
- `--color-paper`: #f4f4f6
- `--color-muted`: #808090
- `--color-black`: #000

## Typography
- Display: Space Grotesk (Medium), roman
- Body: Inter (Regular)
- Mono: JetBrains Mono (EP numbers, quality labels)

## Spacing
4-pt named scale.

## Motion
- Easings: `--ease-out`: cubic-bezier(0.16, 1, 0.3, 1)
- Reveal: fade-only

## Microinteractions
- Silent success.
- Hover: border-color accent only.
- Focus: 2px cyan outline.
